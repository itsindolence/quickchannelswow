# Changelog

## 1.1.0
- Renamed to **QuickChannels** (`/qch`, `/quickchannels`).
- Localization for all game client languages: enUS, ruRU, deDE, frFR, esES/esMX, itIT, ptBR, koKR, zhCN, zhTW.
- Localized button letters, with an option to use English letters (`/qch latin`).
- Party button is always visible (dimmed when not in a group).
- WoW Forever support (interface 16001) and the new Midnight-era chat API.

## 1.0.0
- First release: one-click chat channel bar with active channel highlight, typed-text keeping,
  context menu, vertical layout, fade and scaling.
